# Third-party notices

This directory ships inside the app (`Contents/Resources/LICENSES/`).

Drum machine samples (CC0): [`drum-samples.md`](drum-samples.md), [`CC0-1.0.txt`](CC0-1.0.txt).

## Rust audio crates (linked into the app)

The stem player links Symphonia (MPL-2.0), Signalsmith Stretch through the `signalsmith-stretch` crate (MIT, C++ included), rubato, hound and their dependencies. The list, the license used for each and the source locations are in [`rust-audio-crates.md`](rust-audio-crates.md), and the full texts are in [`rust-audio-crates.txt`](rust-audio-crates.txt). Both are generated by `scripts/collect-audio-licenses.py`. Rerun it when those dependencies change.

## Bundled programs

The app bundles two separate programs as sidecars (`Woodshed.app/Contents/MacOS/`). The app only runs them as child processes; it does not link them. `scripts/fetch-binaries.sh` fetches or builds both with pinned versions and SHA-256 checksums.
